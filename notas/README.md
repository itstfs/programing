# Notas

Anotações de estudo transformadas em resumos com busca e botão de copiar em cada comando.

[← Voltar ao README do projeto](../README.md)

## Resumos

| Nota | Original |
|---|---|
| Banco de dados (MER/DER, chaves, cardinalidade, tipos) | `source/anotações/bd.txt` |
| MySQL (consultas, insert, update) | `source/anotações/mysql.txt` |
| Django (venv, projeto, migrations) | `source/anotações/django.txt` |
| React | `source/anotações/react.txt` |
| React Native | `source/anotações/native.txt` |
| npm e mobile (SemVer, nativo × PWA × híbrido) | `source/anotações/mobile.txt` |
| Formatação do Discord | `source/discord-letters/texts.md` |

Cada resumo tem a aba “Arquivo original”, que mostra o texto como foi escrito.

## Arquivos

```
index.html
assets/css/site.css     ← cartões de nota e busca
assets/js/notes.js      ← busca e botões de copiar
source/                 ← anotações originais, sem alterações
```

O header, o footer e o CSS/JS comuns vêm de [`../shared/`](../shared/README.md).
